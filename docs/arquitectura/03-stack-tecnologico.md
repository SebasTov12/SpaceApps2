# Stack tecnológico

| Área | Tecnología | Uso |
|---|---|---|
| Interfaz | Next.js 16, React 19, TypeScript | Aplicación web y rutas del servidor |
| Estilos e interacción | Tailwind CSS 4, Framer Motion, Lucide React | Diseño adaptable, animaciones e iconos |
| Globo 3D | Three.js, React Three Fiber, Drei | Tierra, relieve, satélites y efectos orbitales |
| Cartografía | MapLibre GL | Mapa de sitio, navegación y capas geográficas |
| API | Python 3.12, Flask 3, Gunicorn | Consultas, ingesta protegida y análisis |
| Persistencia | PostgreSQL 16, psycopg | Catálogo, registros, series y resultados |
| Procesamiento | NumPy, Rasterio, h5py, PyProj, Shapely, Harmony y ASF Search | Ingesta y análisis de productos geoespaciales |
| Modelos | PyTorch y ONNX Runtime | Entrenamiento e inferencia de modelos |
| Operación | Docker Compose, GitHub Actions, GHCR y Caddy | Servicios, imágenes, publicación y proxy TLS |

Las versiones exactas de la aplicación web están en frontend/package.json. Las dependencias de Python se mantienen separadas por servicio en sus respectivos archivos requirements.txt.
