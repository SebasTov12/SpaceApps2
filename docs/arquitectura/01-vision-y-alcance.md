# Visión, propósito y alcance

## Propósito

SAROS es una plataforma geoespacial para explorar registros públicos de afectaciones, consultar información territorial y revisar productos de observación de la misión NASA–ISRO NISAR. Integra mapas, contexto documental y análisis reproducibles para apoyar la evaluación preventiva.

## Experiencia disponible

- Globo 3D con navegación por países, registros geográficos y filtros por tipo de afectación.
- Búsqueda de registros y acceso a la ficha de cada ubicación.
- Vista cartográfica 2D y 3D, con capas y controles vinculados a los productos disponibles para el sitio.
- Fichas con procedencia, fechas, cifras reportadas, precisión geográfica y contexto analítico cuando existe una salida asociada.
- Asistente SARU para explicar la información disponible en español e inglés.
- API y procesos de ingesta para registros históricos, catálogo NISAR y datos territoriales.

## Criterios de uso

Toda cifra debe conservar su fuente, fecha, cobertura y escala. Un registro histórico no equivale a una alerta vigente; una huella de catálogo no equivale a una medición validada; una evaluación estadística no establece causalidad ni probabilidad de desastre.

SAROS apoya la exploración y la planificación. No reemplaza a autoridades, informes técnicos, evaluación de campo ni sistemas oficiales de alerta.
