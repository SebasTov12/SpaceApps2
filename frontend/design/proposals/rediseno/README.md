# Propuesta de rediseño

Prototipos y material de revisión conservados como referencia. Las rutas de imágenes dentro de las maquetas se mantienen relativas para que puedan abrirse localmente.

## Prototipos

- [Rediseño de la página](maquetas/rediseno-pagina.html), con sus imágenes en `maquetas/assets/`.
- [Tres direcciones visuales](maquetas/tres-direcciones.html), con las mismas imágenes locales.
- [Exploración del panel de capas](panel-capas/index.html), acompañada por `panel-capas/nisar-ruiz.js`.

## Muestras y grabaciones

- Audio: `media/audio/`.
- Vídeo: `media/video/`.

Estos prototipos y grabaciones no se cargan en el sitio desplegado. El código activo del aplicativo permanece bajo `frontend/src/` y sus recursos runtime bajo `frontend/public/`.
