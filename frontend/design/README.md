# Diseño y prototipos frontend

Este directorio reúne propuestas visuales, prototipos HTML autónomos y grabaciones de revisión. Es material de referencia: no se importa desde `src/`, no se sirve desde `public/` y no forma parte del frontend que se despliega.

- [Propuesta de rediseño](proposals/rediseno/README.md): maquetas, concepto del panel de capas, muestras de voz y grabaciones.
- El frontend de producción está en `src/`; sus recursos publicados están en `public/`.
